# Lab 1 测试与验收记录

当前仅预留文档入口，由测试负责人根据[作业要求](https://openmsg.yuque.com/openmsg/gp3cfs/srlobx960pg94ozp)编写用例，并在实际执行后填写结果。
框架开发自检不代表完整作业验收通过。

## 待完善内容

- 测试环境、执行人、日期、分支及完整 Commit SHA。
- CodeArts 项目、成员、助教及仓库权限证据。
- 测试用例：前置条件、步骤、预期结果、实际结果和证据。
- 验收范围：干净环境启动、计数加减与负数、刷新及跨浏览器读取、错误提示、服务重启、删除容器后重建及继续读写。
- 容器状态、数据库查询结果和截图（存放于 `docs/images/`）。
- 缺陷、修复后的复测结果及最终验收结论。

尚未执行的用例应标记为“未执行”，遇到阻塞时记录原因；不得将预期结果写成实测结果。
